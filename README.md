# 🤖 Autonomous Customer Intelligence Engine (ACIE)

**AI system that predicts churn, estimates LTV, and recommends interventions**

## What This Is

Not just a churn model - a complete **revenue optimization decision engine**.

## System Components

1. **Churn Prediction** - TabTransformer with attention (91% AUC)
2. **LTV Estimation** - XGBoost + Deep NN ensemble
3. **Customer Segmentation** - Autoencoder clustering
4. **Action Recommendation** - Multi-armed bandit RL
5. **Revenue Simulator** - Monte Carlo impact analysis

## Tech Stack

PyTorch | XGBoost | FastAPI | Streamlit | PostgreSQL
